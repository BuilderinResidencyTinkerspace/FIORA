**Goal this week:** starting to build a prototype of base 

## What we did

our model was inspired by bella, a delivery robot. we plan to start by building the base using form sheet. we cut the sheet into a circular shape with a radius of *cm* to form the base of the model and took measurement of mecanum wheel and cut the sheet according to wheel measurement. so then Completed the basic base structure of the prototype . next we need to design a suitable mounting model to fit and secure the motor into the base .at the same time we realised that our motors wheel hub adapter  could not directly fit into wheel hub. we got stuck at this stage, so we searched online for a suitable adapter. however the available option were too expensive. so we decided to make one ourselves. we then started to design for a custom motor to wheel adapter. so we started to explore CAD and it was a long process.
